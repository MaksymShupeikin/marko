## Группа 7 — Состязательные входы LLM (§13.7)

Контур в режиме `off`, поэтому всё ниже — **проектные требования, не
результаты испытаний**.

| # | Атака | Заявленная защита | Проверено |
|---|---|---|---|
| A-01 | Инструкция в названии товара | system instructions запрещают исполнять команды из карточки | **нет** |
| A-02 | Инструкция в описании | то же | **нет** |
| A-03 | Инструкция в характеристиках | то же | **нет** |
| A-04 | Инструкция в URL | то же | **нет** |
| A-05 | Инструкция в изображении | то же | **нет** |
| A-06 | Ответ вне схемы | строгий Structured Output; отказ → `INSUFFICIENT_DATA` | **нет** |
| A-07 | Timeout провайдера | fail-closed → `INSUFFICIENT_DATA` | **нет** |
| A-08 | Отравление кэша через изменение карточки | ключ кэша включает содержимое карточки | **нет** |
| A-09 | Положительная коррекция человека в обход hard stop | коррекция не может обойти детерминированный стоп | **нет** |
| A-10 | Утечка каталожных данных во внешний сервис | требуется разрешение владельца | **не получено (DB-06)** |

**Это самый слабый участок программы.** Десять заявленных защит, ноль
испытаний. Ни одна не может считаться работающей до shadow-прогона.
