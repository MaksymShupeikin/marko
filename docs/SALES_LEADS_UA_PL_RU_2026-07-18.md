# Marko: лид-база магазинов автозапчастей — Украина, Польша, Россия

Дата проверки: 2026-07-18  
Статус: desk research; контакты взяты только из публичных бизнес-страниц компаний.  
Цель: найти design partners и первых платных пилотных клиентов для Marko.

## 1. Что продаём

Marko — операторский инструмент ценовой аналитики для продавцов автозапчастей:

- импорт собственного каталога из XLSX;
- нормализация и сопоставление сопоставимых деталей и аналогов;
- расчёт объяснимой рекомендации цены по рыночным наблюдениям;
- раздельные сценарии повышения цены, clearance и ручной проверки;
- решение оператора `accept / reject / override` с журналом доказательств;
- без автоматической публикации цены в магазин на текущем этапе.

Для пилота безопасно обещать только работу с клиентским XLSX и разрешёнными/предоставленными источниками данных. Live-сбор публичных конкурентных данных Prom.ua в текущей конфигурации проекта закрыт fail-closed source-access gate.

## 2. ICP и логика оценки

Лучший первый клиент:

1. независимый магазин или региональная сеть, где решение может принять владелец/руководитель e-commerce;
2. каталог от 5 000 SKU или несколько ценовых каналов;
3. собственный сайт плюс Prom.ua / Allegro / Ozon / Wildberries;
4. оригинальные детали и аналоги создают реальную проблему сопоставимости;
5. цены обновляются вручную, прайсами поставщиков или простыми наценками;
6. компания готова дать XLSX-выгрузку 50–200 SKU для контролируемого пилота.

Оценка `fit / 5` — исследовательская, не подтверждённый budget/authority/need. Она учитывает размер и сложность каталога, совпадение канала с Marko, доступность лица для контакта и выраженность ценовой боли.

## 7. Предложение пилота

Не продавать «оптимальную цену» или «полный автоматический repricing». Продавать измеримый диагностический пилот:

- вход: XLSX клиента с 50–200 SKU, текущей ценой, себестоимостью и по возможности остатком;
- рынок: только источник, который клиент имеет право предоставить или использовать;
- результат: список `RAISE / CLEARANCE / MANUAL_REVIEW / INSUFFICIENT_DATA`, доказательства по каждой рекомендации и список проблем каталога;
- контроль: Marko не меняет цену автоматически;
- срок: согласовать после получения образца данных, не обещать заранее;
- метрики: доля сопоставленных SKU, доля рекомендаций с достаточными доказательствами, потенциальная валовая маржа, время оператора, доля отклонённых рекомендаций;
- коммерческий переход: платный месячный пилот только после бесплатного 30-минутного discovery и проверки образца XLSX.
