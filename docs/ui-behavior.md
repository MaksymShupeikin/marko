# Поведение интерфейса: экран за экраном, кнопка за кнопкой

Спека того, **что должен делать каждый элемент**. Формат одинаковый:

- **Действие** — что происходит по нажатию;
- **Состояния** — что видит пользователь в loading / success / empty / error;
- **Статус** — `✅ работает` / `⚠️ работает частично` / `❌ не сделано`.

Правило, которое действует для всего интерфейса и не повторяется в каждом
пункте: **у любого элемента, который ходит в сеть, обязаны быть все четыре
состояния**. Кнопка без состояния «ошибка» считается недоделанной.

## 3. Панель товара (`widgets/product_details_panel.dart`)

| Элемент | Должно быть | Сейчас | Статус |
| --- | --- | --- | --- |
| Факты: артикул, бренд, OEM, магазин, обновлено | как есть | как есть | ✅ |
| Чипы OEM-номеров | все номера из `raw_data.oem_numbers` | как есть | ✅ |
| «Відкрити на Prom» | внешняя ссылка в новой вкладке | как есть | ✅ |
| **Блок «Ціни конкурентів»** | **при открытии панели автоматически** дёргается `GET /api/v1/competitors/avtopro` с `oem` = `primaryOem`, `brand` = бренд товара, `name` = название товара; показываются мин/медиана/макс, позиция моей цены и топ предложений | статичная заглушка «з'явиться тут» | ❌ |

Это главный разрыв продукта: сценарий из `product-vision.md` §4 в UI не
существует. Требования к блоку, когда он будет сделан:

- **loading** — скелетон внутри блока, панель товара при этом уже открыта и
  листается (проверка цен не блокирует остальную карточку);
- **success** — мин/медиана/макс, дельта своей цены к медиане в % и в грн,
  до 10 предложений (продавец, город, наличие, цена), ссылка на avto.pro;
- **empty** — «по номеру `X` на avto.pro пропозицій немає» + кнопка
  «Спробувати інший номер» (даёт выбрать из остальных OEM товара);
- **error** — «avto.pro не відповідає» + «Повторити»; ошибка живёт внутри
  блока и не роняет панель;
- **нет OEM** — блок не грузится, показывает, чего не хватает в товаре.

> ❓ Решить: считать «мою цену» от `current_price` товара или от цены с учётом
> скидки; и с чем сравнивать по умолчанию — с минимумом или медианой рынка.

## 6. Общие правила, обязательные для каждой новой кнопки

1. Кнопка, отправляющая запрос, **блокируется на время запроса** и показывает
   спиннер в себе — не поверх экрана.
2. Любая ошибка формулируется в терминах пользователя. `Exception: 502` в
   интерфейсе — это баг, а не сообщение.
3. Долгие операции (> 3 с) переживают закрытие модала.
4. Любой список имеет вид «пусто»: текст + следующее действие.
5. Действие, у которого нет обратной связи через 1 секунду, воспринимается как
   сломанное — нужен хотя бы скелетон.
6. Ничего не требует знаний о внутренностях: если полю нужен бренд или OEM,
   оно подставляет их из товара, а не ждёт ввода.
