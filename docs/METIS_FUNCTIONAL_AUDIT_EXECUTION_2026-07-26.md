### Три находки, наиболее заметные заказчику

**F-0001 — пользователь видит английский мусор в самом частом случае.**
`pricing_models.dart:289` при неизвестном коде выводит
`code.toLowerCase().replaceAll('_',' ')`. Из 40 кодов, которые способен выдать
бэкенд, 22 отсутствуют во фронтенде полностью. Среди них `UNKNOWN_TIER` и
`APPLICABILITY_UNKNOWN` — а это ровно те вердикты, которые сейчас доминируют
(`REVIEW 2189` из 8437 карточек). То есть дефект проявляется не в краевом
случае, а в основном.

**F-0003 — импорт каталога есть, интерфейса нет.**
Три эндпоинта `/catalog/imports` не вызываются ни одним файлом `frontend/lib`.
Заказчик с каталогом на 4901 позицию не может обновить его сам.

**F-0005 — украинский рынок, русские ошибки.**
634 литерала локализованы правильно через `context.localized(ru:, uk:)`,
263 — нет. В том числе **все 19 сообщений об ошибках входа**
(`firebase_auth_client.dart`): украинский пользователь при неверном пароле
получит русский текст.

## 5. Что проверено и признано НЕ дефектом

Раздел обязателен: без него реестр выглядит страшнее, чем система есть.

| кандидат | вердикт |
|---|---|
| `cross_links.py:98`, `pricing_runs.py:929` — select без workspace_id | **не дефект**: фильтр по `pricing_run_id`, который сам принадлежит workspace (транзитивная изоляция) |
| 10 из 11 проглоченных исключений | **не дефект**: parse-or-None хелперы, закрытие тестового ответа, битый `Retry-After` → дефолтный backoff |
| `xlsx_catalog.py:479` `except ValueError: pass` | **не дефект, а fail-closed**: при неисправном keyring импорт себестоимости запрещается, а не разрешается |
| `catalog_discovery.py:320` | **не дефект**: нет идентификатора → нет снимка, корректная семантика |
| 11 из 14 «денег во float» | **не деньги**: коэффициенты сжатия, длительности, эффективность параллелизма |
| 634 из 897 литералов | **локализованы** через `localized(ru:, uk:)` |
| `TOO_FEW_COMPETITORS` в первом прогоне | **ложное срабатывание регулярки**, код в UI есть — пересчитано |
| CASCADE на `catalog_discovery_offers/captures` | **приемлемо**: производные строки каскадируются, сырые блобы защищены `RESTRICT` |
