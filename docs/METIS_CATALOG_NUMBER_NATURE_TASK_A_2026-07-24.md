## Метод

Приоритет правил:

1. независимое exact-предложение не от магазинов Юрия;
2. fail-closed проверка KEMP-паттерна;
3. отдельный KEMP-код в поисковых запросах той же строки;
4. manufacturer-pattern из client-specific config вместе с контекстом марки;
5. иначе `UNKNOWN`.

Паттерны находятся в `backend/config/catalog_number_nature.yaml`, а не в коде.
Результат воспроизводится командой:

```bash
cd backend
uv run python ../scripts/classify_catalog_numbers.py
```

Полная таблица и 20 примеров каждого типа находятся в
`outputs/metis_catalog_number_nature_20260724/METIS_CATALOG_NUMBER_NATURE_TASK_A.xlsx`.
