# ЗАМЕР: kemp.ua как источник OE

**Дата:** 2026-07-29
**Вопрос:** стоит ли добавлять сайт заказчика четвёртым источником номеров
к блоку характеристик, справочнику KEMP и описаниям конкурентов.
**Ответ:** да. Основная выборка даёт 35% закрытия дефицита, контрольная —
99.4% точности. Пакет работ вписан в мастер-промпт как WP-1B.

---

## 1. Метод

Две независимые выборки из справочника KEMP (4646 строк).

**Основная — 100 из 1385.** Генеральная совокупность: строки, у которых
`фирма по артикулу` — поставщик компонентов (Sachs, FAG, Nissens, …), а не
автопроизводитель. Для них артикул не является OE, и OE не берётся ниоткуда.
Вопрос: сколько таких позиций закроет сайт.

**Контрольная — 200 из 3252.** Генеральная совокупность: строки с брендом
автопроизводителя, у которых OE известен из справочника. Вопрос: насколько
сайт точен там, где ответ проверяем. Без неё первая цифра непроверяема.

Обе выборки — систематические, шаг 13.85 и 16.26 по (бренд, внутренний код),
то есть пропорционально распределению брендов. Основная: Sachs 21, FAG 15,
Nissens 7, GKN-Spidan 6, K+F 6, Lesjofors 6, Kolbenschmidt 5, дальше хвост.
Контрольная: VAG 97, General Motors 28, Mercedes 21, Ford 18, дальше хвост.

**Процедура на позицию.** Поиск по внутреннему коду
(`/index.php?route=product/search&search=<mpn>`) → карточка товара → три поля
`ОЕ номер` / `Артикул` / `Номер виробника`. **Товар засчитан только при
точном равенстве `Номер виробника` нашему коду**: поиск на сайте цепляет и
описания, попадание в выдаче доказательством не является. Из-за этого 135
поисковых ответов основной выборки развернулись в 135 карточек, а 200
контрольных — в ~595.

830 запросов суммарно, пауза 1.5 с, ответы закешированы на диск.
`robots.txt` не запрещает `route=product/search`.

**Разбор значения — токенами.** Значение режется по `/`, `,`, `;`; каждый
токен нормализуется (в том числе снимается хвост `.0`, который Excel
оставил на числовых артикулах) и сверяется с известными номерами и с
формами артикулов поставщиков (`VKBA\d+`, `713\d{6}`, `OP-ES-\d+`, `GN\d{3}`,
`FT\d{4}`, суффикс `/MG`).

## 3. Контрольная выборка: насколько точен

| | доля | |
|---:|---:|---|
| 152 | 76.0% | подтвердил OE справочника, поле `ОЕ номер` |
| 9 | 4.5% | подтвердил OE справочника, поле `Артикул` |
| 1 | 0.5% | **противоречит справочнику** |
| 1 | 0.5% | у справочника нет OE (артикул = внутренний код) |
| 37 | 18.5% | товара нет на сайте |

**Из 162 проверяемых позиций сайт подтвердил 161 — 99.4%.**

Единственное противоречие:

```
77647977  Renault (RVI)  справочник 7701059269  сайт 7701050685
          Переключатель стеклоочистителей Renault Trafic 2 / Master 2
```

Оба номера — настоящие Renault формы. Это либо замена номера (supersession),
либо ошибка в одном из источников. Разрешается человеком, а не правилом;
до разрешения обе связи живут в графе с разным `extraction_method`, и
именно ради таких случаев NO_7 запрещает смешивать доверие источников.

Побочно: во всём справочнике только 3 строки из 4646 имеют артикул, равный
внутреннему коду, и 8 строк с пустым артикулом. Эти 11 позиций не должны
получать `oe_norm` ни при каких условиях (NO_5).

## 4. Главная находка: подписи полей ничего не значат

Карточка товара:

```
product-data__item model → «ОЕ номер:»        → 443121251T
product-data__item sku   → «Артикул:»         → AI2091
product-data__item mpn   → «Номер виробника:» → 77642803
```

Из 35 найденных настоящих OE **26 лежали в поле «Артикул»** и лишь 9 — в
поле «ОЕ номер». В контрольной выборке соотношение обратное: 152 против 9.

Объяснение простое и оно же делает правило устойчивым: когда OE известен
заказчику, он попадает на «правильное» место; когда неизвестен — заказчик
кладёт в «Артикул» то, что знает, а туда попадает и настоящий OE, часто
склеенный через `/` с артикулом поставщика.

```
Sachs  77648745  справочник 313856      ОЕ номер 313856     Артикул GJ5A28700B          ← Mazda
Sachs  77648803  справочник 339242      ОЕ номер 339242     Артикул 4851080490          ← Toyota
FAG    77647561  справочник 713610640   ОЕ номер 713610640  Артикул 713610640/7L0498287 ← VAG
INA    77642917  справочник 531039920   ОЕ номер 531039920  Артикул 06B109243           ← VAG
```

**Следствие для разбора:** брать оба поля, резать по разделителям,
классифицировать каждый токен по форме. Классификация по имени поля даст
ошибку в две трети случаев на той совокупности, ради которой сайт и берут.

## 5. Оговорка о методе

Отнесение «это OE такой-то марки» в разделе 2 сделано по форме номера
человеком, а не сверкой с базой OE. Формы VAG (3+3+3), Mercedes
(`000 323 28 85`), Renault (10 цифр), PSA (`6455.EE`, `1301SJ`), Toyota,
Hyundai, Mazda различимы уверенно; спорные вынесены в отдельную строку
таблицы и в успех не записаны. Раздел 3 этой оговорки не требует: там
сверка идёт с известным ответом.

Цифра 35% — оценка по выборке 100, доверительный интервал Уилсона 95%
примерно 26-45%. Даже нижняя граница делает пакет оправданным.
