## 3. ЧТО ОКАЗАЛОСЬ НЕ ТАК, КАК ПРЕДПОЛАГАЛОСЬ

### 3.1. В описаниях наших товаров кросс-таблиц НЕТ

Проверено по всем 4901 строкам:

```
описаний непустых            4901
содержат <table>                0
содержат «КАТАЛОЖНІ НОМЕРИ»     0
содержат «ЗАСТОСУВАННЯ»         0
HTML_опис непустых              1
```

`Опис` — маркетинговый шаблон: «Здравствуйте! Благодарны Вам за интерес к
Запчасти Торговой Марки "КЕМР"…», далее название и картинки.

**Таблицы «КАТАЛОЖНІ НОМЕРИ АНАЛОГІВ» и «ЗАСТОСУВАННЯ» со скриншотов
принадлежат карточке конкурента (Metzger / Партс Тайм), а не нашей.**
Гипотеза, на которой строился WP-1 первой редакции («парсер описания
собственной карточки»), для этого каталога неверна и снята.

### 3.2. Товара `2141006` в экспорте нет вовсе

Поиск подстроки по всем 87 колонкам всех 4901 строк — 0 совпадений.
Экспорт датирован 10.07.2026, наблюдение со скриншота — 27.07.2026.
**Перед началом работ требуется свежий экспорт**, иначе golden-фикстура
и метрики будут построены на устаревшем срезе.

### 3.3. `Код_товару` в большинстве случаев уже содержит настоящий артикул

Форма значений: 2247 чисто цифровых, 2088 буквенно-цифровых, 566 внутренних
KEMP-номеров вида `776*`. Примеры: `93818439` (GM), `056121113D` (VAG),
`357905851D` (VAG), `1086282` (Ford), `HIS-25`.

**2895 значений `Код_товару` совпадают с артикулом из справочника KEMP** —
подтверждение, что это настоящие номера производителей, а не внутренние
коды. Исходная формулировка Ф-1 («колонка `oe` набивается артикулом
продавца») верна лишь для 566 позиций из 4901, а не для всего каталога.

## 4. ПОКРЫТИЕ СПРАВОЧНИКА KEMP

| Сопоставление | Товаров | Доля |
|---|---|---|
| `Код_товару` → KEMP-номер | 504 | 10.3% |
| `Код_товару` → KEMP-артикул | 2895 | 59.1% |
| `Номер_пристрою_(MPN)` → KEMP-артикул | 2327 | 47.5% |
| Любое поле → KEMP-номер | 506 | 10.3% |
| Любое поле → KEMP-артикул | 3007 | 61.4% |

**Классификация бренда артикула через справочник** (по объединению
`Код_товару` + `Код запчастини`):

```
OE (автопроизводитель)   2704   55.2%
AFTERMARKET               990   20.2%
нет совпадения           1207   24.6%
```

Внутренних кодов `776*` в экспорте 566, из них **504 разрешаются
справочником, 62 — нет** (`776414`, `7764112`, `7764160`, `7764228`,
`7764262`, `7764267`, `7764346`, `7764349`, `7764365`, `7764397`,
`7764436`, `7764527`, `7764528`, `7764612`, `7764625`, `7764626`,
`7764755`, `7764799`, `7764843`, `77641041`, …). Это 6-7-значные формы
при преобладающей в справочнике 8-значной — вероятно усечение или иная
генерация номера. Требует ответа владельца данных.

**Пересмотренная ценность справочника KEMP.** Как источник номеров он
почти избыточен: экспорт уже содержит настоящие артикулы. Его
незаменимая функция — **бренд артикула**, потому что колонка `Виробник`
в экспорте равна `KEMP` у 4616 товаров из 4901 (94.2%) и для определения
тира и различения OE/афтермаркет бесполезна. Справочник даёт этот бренд
для 3007 позиций (61.4%).

## 6. ДВЕ ЛОВУШКИ НОРМАЛИЗАЦИИ, ОБНАРУЖЕННЫЕ В ДАННЫХ

**6.1. Пробел внутри номера.** 129 значений `Код запчастини` содержат
номер с внутренним пробелом (`776414, 115 070,` — это `115070`, а не два
номера). Разбор по запятой обязан выполняться до нормализации, а
нормализация — схлопывать пробелы; иначе один номер превратится в два
мусорных токена.

**6.2. Гомоглиф в имени характеристики.** В экспорте одновременно
присутствуют `Модель` (51 товар) и `Мoдель` (149 товаров) с латинской
`o`. Механизм схлопывания уже есть (`_HOMOGLYPHS`, `xlsx_catalog.py:45`),
но применяется только к значениям идентификаторов, не к именам
характеристик.
